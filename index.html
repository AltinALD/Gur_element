The studio

Landscape, memory and time.

Gur Element is contemporary jewellery from Albania. Each work is a conceptual artefact, handcrafted in silver and set with ethically collected stones.

  • One maker Crafted by one. Every piece leaves the same bench.
  • Silver & stone Sterling silver, enamel, and stones collected with care.
  • Made in Albania Rings, earrings, necklaces and brooches from the studio.
